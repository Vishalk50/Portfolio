# PRD — Vishal Khajuriya Portfolio

## App Name
Vishal Khajuriya — AI Product Builder Portfolio

## Tagline
I design AI products. AI builds them.

## Problem
Vishal needs a professional portfolio to attract freelance clients on Fiverr/Upwork. Current single-page HTML is functional but lacks:
- Individual project pages with detail
- Service offerings section for freelance pitching
- Contact form for client inquiries
- Resume download
- Modern, polished design that impresses potential clients

## Target User
- **Freelance clients** on Fiverr/Upwork looking for AI product builders
- **Recruiters** evaluating Vishal's project portfolio
- **Collaborators** interested in his AI workflow

## Must-Have Features
1. Home page with hero, about, featured projects, skills, services
2. Individual project pages with full description, tech stack, screenshots, links
3. Services/offerings section with CTA
4. Contact form (Formspree backend — free tier)
5. Resume/CV download button
6. Smooth animations and modern dark-purple design
7. Responsive on mobile, tablet, desktop
8. Deployed to GitHub Pages

## Nice-to-Have Features
- Blog/writing section (post-MVP)
- Dark/light theme toggle
- Project filter by status (Complete / In Progress)
- Analytics (Plausible or similar)

## Out of Scope
- User authentication
- Database backend
- E-commerce / payment processing
- CMS integration

## Success Metrics
- Portfolio loads in <2s on 3G
- Lighthouse score >90 all categories
- Contact form submissions received
- GitHub Pages deployment working
